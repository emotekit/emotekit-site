EmoteKit（以下「当方」）は、「びちゃ犬」（以下「本アプリ」）および関連サービスにおけるユーザーのプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシー（以下「本ポリシー」）は、本アプリにおける情報の取扱いについて定めるものです。

第1条 取り扱う情報

本アプリでは、サービス提供のため、次のカテゴリの情報を取り扱います。ゲームデータは原則としてユーザーの端末内で処理・保存し、当方のサーバーへ送信するものではありません。外部サービスへの送信については第5条に定めます。

  • プロフィール・サービス利用情報：ユーザーが設定した名称等のプロフィール、ゲームの進行・利用記録、共有機能で取り込んだ情報、所持コンテンツおよび各種設定。
  • 取引情報：購入履歴、取引識別情報、購入・定期購入の確認結果および特典等の付与記録。決済手段の詳細は各ストアが管理し、当方はクレジットカード番号等を取得しません。
  • デバイス・技術情報：広告・決済等の外部サービスの提供に伴う端末・OS・アプリの情報、IPアドレスおよびそこから推定されるおおよその位置、識別子、利用状況および診断情報。
  • 同意・選択に関する情報：利用条件の確認、広告に関する同意・選択および端末の権限設定。
  • サポート関連情報：お問い合わせ時にユーザーから提供されるメールアドレス、問い合わせ内容および調査に必要な情報。

マイクは音量判定のために使用し、音声の録音ファイルの作成や音声の外部送信は行いません。ユーザーが開始した音量判定は、OSが許可する範囲でバックグラウンドでも継続し、ユーザーの終了操作や権限の取消しにより停止します。カメラはユーザーが選択したQRコードの読み取りに使用し、撮影画像を当方へ送信しません。通知は端末の許可に基づいて行います。これらの権限を許可しない場合、対応する機能は利用できません。

第2条 情報の利用目的

当方および本アプリは、前条の情報を、次の目的で利用します。

  • 本サービスの提供、ゲームデータの保存・表示およびユーザーが選択した機能の実行
  • 購入の確認、定期購入の管理、商品の提供および重複・不正な付与の防止
  • 広告の配信、効果測定および不正利用の防止
  • ユーザーサポート、不具合の調査およびサービスの安全性・品質の維持
  • 同意・権限の管理、必要なお知らせおよび法令に基づく対応

第3条 情報の管理と保護

1. 本アプリは、当方のアカウント登録、当方によるゲームデータのクラウド保存・同期を提供していません。端末内の情報には、端末およびOSの保護機能が適用されます。OSのバックアップ等を利用する場合は、その提供者の条件に従って情報が保存される場合があります。

2. 当方がサポート等で取得した個人情報については、アクセス制限その他の適切な安全管理措置を講じ、必要に応じて委託先を監督します。

3. 広告、ストア等の外部サービスでは、提供者の所在国その他の日本国外で情報が取り扱われる場合があります。提供者、取扱情報および各社の保護方針は、第5条のリンクから確認できます。法令上必要な同意その他の手続を行います。

第4条 第三者への提供

当方は、本人の同意がある場合、法令に基づく場合、生命・身体・財産の保護等のため法令上認められる場合を除き、個人情報を第三者へ提供しません。利用目的の達成に必要な範囲での取扱いの委託および事業承継に伴う提供についても、適用法令に従います。ユーザーが選択して行う情報共有については、第5条に定めます。

第5条 外部サービスの利用

本アプリおよび関連ウェブサイトは、次の外部サービスを利用します。各提供者は、それぞれの利用条件およびプライバシーポリシーに従って情報を取り扱います。

  • Google AdMob・User Messaging Platform（Google LLC）
    用途：広告の配信・効果測定、不正防止および広告に関する同意管理。
    取り扱われる情報：IPアドレスおよびそこから推定されるおおよその位置、端末・OS・アプリ情報、広告の表示・操作等の利用状況、診断情報および同意状態。広告識別子等の取扱いは、端末の設定、同意状態および未成年者保護の設定等に従います。
    Google プライバシーポリシー / Googleによるパートナーの情報の使用
  • App Store（Apple）・Google Play（Google）
    用途：商品の購入、決済、購入確認および定期購入の管理。
    取り扱われる情報：ストアアカウントに関連する取引・決済情報、端末情報等。アプリは購入確認に必要な取引情報を受け取ります。
    Apple プライバシーポリシー / Google プライバシーポリシー
  • ユーザーが選択する共有先
    用途：画像・コード等の共有。選択した内容が共有先へ渡され、その提供者の条件に従って取り扱われます。ユーザーが選択せずに、当方が共有先へゲームデータを公開することはありません。
  • GitHub Pages（GitHub）
    用途：本サービスの案内・法務ページ等の配信。ページへのアクセス時にIPアドレス等の通信情報が取り扱われます。
    GitHub プライバシーに関する声明

第6条 Cookie・類似技術とユーザーの選択

広告等の外部サービスは、識別子その他Cookieに類似する技術を使用する場合があります。本アプリは、パーソナライズ広告を要求しません。本アプリでは、適用される同意・未成年者保護の設定に従って広告を取り扱います。広告の同意変更が必要な地域等では、本アプリ内の広告プライバシー設定から選択肢を確認できます。端末のプライバシー設定から、広告識別子やアプリの権限を管理できます。設定の変更後も、広告の配信や不正防止に必要な情報の処理が行われる場合があります。

第7条 データの保持期間・削除

1. 端末内のゲームデータは、本アプリのデータ消去機能等により削除できます。不正な再付与を防ぐための最小限の記録および端末の安全な領域に保存する共有機能の認証情報は、消去後も残る場合があります。削除したゲームデータは当方で復元できません。端末やOSのバックアップ、ユーザーが保存した画像、共有先の情報等は別に管理・削除する必要があります。

2. お問い合わせ等で当方が取得した情報は、対応および利用目的の達成に必要な期間保持し、不要となった場合は削除または個人を識別できない状態にします。ただし、法令に基づく保存、不正防止および紛争対応に必要な情報は、必要な期間保持する場合があります。

3. ストア、広告その他の外部サービスが保持する情報の削除等は、各提供者の窓口・設定により行ってください。本アプリのデータ消去によって、各社の取引記録が削除されたり、定期購入が解約されたりすることはありません。

第8条 ユーザーの権利

当方が保有する本人の個人情報について、利用目的の通知、開示、訂正、削除、利用停止等を希望する場合は、第11条の窓口へご連絡ください。本人確認の上、適用法令に従って対応します。当方が保有していない端末内の情報については、端末内の設定等から管理できます。

第9条 未成年者の利用

本アプリは13歳以上の方を対象とし、未成年者の利用には法定代理人の同意を必要とします。広告には未成年者保護の設定を適用します。保護者の方は、お子様の情報共有、端末の権限および課金機能の利用についてご確認ください。

第10条 本ポリシーの変更

法令の改正やサービスの変更等に伴い、本ポリシーを変更することがあります。重要な変更は、本アプリまたは本サービスのウェブサイトで、内容および適用時期を周知します。法令上、本人の同意が必要な場合は、適切な方法で同意を得ます。

第11条 お問い合わせ

本ポリシーおよび個人情報の取扱いに関するお問い合わせは、EmoteKit（contact@emotekit.com）へご連絡ください。事業者に関する情報および開示窓口は、特定商取引法に基づく表記に掲載しています。

第12条 準拠法

本ポリシーは日本法に準拠し、日本法に従って解釈されます。
